# LANSEIR Inheritance Pack Specification
Status: CANONICAL · MIGRATION-CRITICAL
Promotion: FULL SEND — 2026-08-26

## Purpose
Preserve institutional identity and reasoning independently of model, vendor, host, database, or application stack.

## Required Payload
1. LANSEIR Constitution / Identity Charter
2. Master Operating Doctrine
3. Operating Character
4. LANSEIR Expression Profile
5. Capability Architecture
6. Canonical Decisions
7. Source-of-Truth Registry
8. Decision provenance and rationale
9. Specialist inheritance rules
10. Migration manifest and integrity hashes
11. Version/change-control metadata
12. Validation criteria

## Migration Gate
A migration is not complete merely because files or databases transferred. It passes only when:
- canonical authority is preserved;
- identity and expression behavior are intact;
- provenance remains queryable;
- specialists inherit current doctrine;
- Presence/Orientation resolves the correct Now;
- validation confirms no material identity or governance drift.

## Principle
Identity first. Intelligence second. Infrastructure remains replaceable.
