# Client Experience SOP

## Standard

Client execution follows the same constitutional path as founder operations:

INTENT → ROUTING → SPECIALIST EXECUTION → VALIDATION → DELIVERABLE → NEXT ACTION

The client receives one accountable lead, one integrated result, the exact
artifact when applicable, a complete copy-ready handoff, verified status, and a
clear next action. CADRE owns context continuity; the client does not rebuild it.

## Friction controls

- Ask only for information, consent, credentials, or judgment that materially
  blocks safe execution.
- Reuse canonical project state and approved decisions across authorized
  channels.
- Do not require manual copying when an authorized API, automation, or direct
  execution path exists.
- Keep ownership, dependency, due artifact, validation state, and next action
  explicit.
- Do not report completion or deployment readiness above the evidence achieved.

## Acceptance

Client mode passes only when the specialist team, self-contained artifact,
validation, privacy boundary, delivery pair, and next action match founder-mode
quality for the same objective.
