# Global Input and Handoff SOP

## Input parity

Voice, typed chat, mobile, desktop, command surface, API, agent-to-agent,
automation, delegated, and future supported inputs enter the same Universal
Prompt Gateway. Interface metadata is recorded for audit and regression; it
does not change specialist authority, completeness, validation, or delivery.

Speech transcription errors that materially alter scope, identity, destructive
effect, credentials, or legal/financial consequence require clarification.
Ordinary wording variation does not.

## Copy-ready handoff

Every substantive gateway artifact includes the objective, governing authority,
specialist team, canonical references, constraints, requirements, dependencies,
security, preservation, commands/configuration when known, validation,
acceptance, outputs, reporting, rollback, and handoff identifier. The note is a
discrete block that can be sent directly to the receiver.

## Dual delivery

When a file applies, return the registered artifact with locator and SHA-256,
plus its complete execution note. Never reconstruct a protected source from
conversation. Never replace a due artifact with an acknowledgment or status.
